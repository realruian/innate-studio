# Innate Studio

通过火山方舟或 Flatkey 生成视频、图片和音频的本地网页应用。火山方舟是字节官方的接口：视频用 Seedance，图片用 Seedream，润色用豆包的文本模型。Flatkey 上视频用 Seedance 和 Grok，图片用 Grok，语音和音效用 ElevenLabs，还能给视频配乐。两个平台在「设置」里切换，见下面的[两个平台](#两个平台)。

## 第一次使用

1. **安装 Node.js**（22.18 或更高）。到 <https://nodejs.org> 下载 LTS 版本，一路下一步装好。
2. **双击启动**。Mac 双击 `start-mac.command`，Windows 双击 `start-windows.bat`。会弹出一个黑色窗口，并自动在浏览器里打开页面。第一次启动要联网下载页面用到的依赖，大约一分钟。
3. **填 API Key**。第一次打开会弹出「设置」，把自己的 Flatkey API Key 粘贴进去保存。Key 在 [Flatkey 控制台](https://console.flatkey.ai/keys?lng=zh)创建。

之后每次要用，双击启动文件就行。**那个黑色窗口开着，服务就在运行；关掉它，页面就打不开了。**

Mac 第一次双击可能被系统拦住，提示"无法验证开发者"。这时在文件上点右键，选「打开」，再点一次「打开」；如果还不行，到「系统设置 → 隐私与安全性」里点「仍要打开」。只需要做一次。

### 用命令行启动

不想用启动文件的话，在终端里进入这个文件夹。第一次先安装依赖：

```bash
npm install
```

之后每次启动：

```bash
npm start
```

它会先把页面构建一遍，再启动服务。然后在浏览器打开 <http://127.0.0.1:5178>。换端口：`PORT=5180 npm start`。

## 功能

能生成五种内容，在输入框上方切换。具体能用哪些，取决于你的 Key 开通了哪些模型：

- **视频（Seedance）**：文生视频、首尾帧、全能参考（图片最多 9 张，视频和音频各最多 3 段）。参数有模型、分辨率、画面比例、时长、生成有声视频、水印、随机种子、联网搜索、输入模式、画质超分
- **视频（Grok）**：文生视频、图生视频（给一张首帧）。时长 1 到 15 秒，480p 或 720p
- **图片**：一次 1 到 4 张，七种画面比例。生成的图可以直接拿去生成视频：Seedance 把它当参考图，Grok 把它当首帧。在火山方舟上可以带参考图（图生图）：加一张或几张图，按提示词改它，Seedream 5.0 pro 和 flash 最多 10 张，5.0 最多 14 张；Flatkey 上生图不能带参考图
- **语音**：把文字读出来，音色可以先试听再选
- **音效**：按描述生成一段声音，可以指定时长
- **配乐**：选一段视频，生成一段和它一样长的音乐；在详情里可以对着画面听
- **润色**：视频、图片、音效的提示词可以让文本模型补充得更具体，不满意可以撤销。改写的规则跟着要用的生成模型走：Seedance、Grok、ElevenLabs 各按自己官方的提示词写法来，首尾帧和全能参考也各有侧重。用哪个文本模型在设置里选；选的模型调不通时会自动换一个
- **画布**：一个项目是一张可以无限平移缩放的画布，在「画布」页的项目列表里新建、重命名、删除；点进去之后整个窗口都是画布，左上角返回。节点有文本、图片、视频、音频四种，从左侧工具栏添加，或者双击空白处；节点本身只放内容，选中之后下方出现输入面板（参考素材、提示词、模型和参数、生成键）。文本节点可以自己写，也可以让文本模型写（用的是润色那一组模型）。节点两侧的加号拖出去是连线，点一下是在那一侧接一个新节点。左侧工具栏还可以从素材库挑素材、上传本机的图片和视频（也可以直接把文件拖进画布）。文本连过去是提示词；图片连到视频是参考图，可以改成首帧或尾帧；图片连到图片是图生图（只在火山方舟上能连）；视频、音频连到视频是参考素材。生成的结果同时出现在创作记录里，改动自动保存
- **角色**：把一个角色的名字、描述和最多 6 张参考图存起来。点角色的封面，就带着它的参考图去生成图片；「更多」里可以带去生成视频。创作页添加参考图时，也能从「角色」这个来源里直接选。图片记录的「更多」里有「存为角色」。带参考图生成图片只在火山方舟上可用
- **技能**：一个技能是一套写提示词的规则。在创作页输入框右下角点「技能」选一个（视频和图片各有各的），只写一句简单的话，发送时文本模型按规则把它扩写成完整的提示词再去生成；输入框里留着的还是你写的那句话，扩写后的提示词在记录的详情里。内置三个官方技能：多镜头成片（视频）、角色设定图、分镜首帧（图片）。在「技能」页可以查看官方技能的规则，也可以新建自己的技能。选了技能就不再显示「润色」

其他：

- 参考素材的来源：本地上传、素材库（含真人素材）、已经存到本机的生成记录、角色。添加时不用先选类型，上传的是什么就算什么
- 素材库：上传文件、用链接创建、按 ID 添加、查看可用模型、删除
- 真人档案：创建档案、生成认证链接、添加和删除真人素材
- 创作记录：单独一页，进度、播放、下载、复用参数、详情，按类型筛选，可以搜索提示词；创作页下方只列最近 6 条
- 延长和编辑视频（Seedance）：在视频卡片的「更多」里。延长是接着原视频往下生成，编辑是只改指定的东西、镜头和动作不变。这两种在 Flatkey 上用 seedance-2.0、480p 实测过；开着「生成有声视频」时失败过一次（平台提示声音可能涉及版权）
- 设置里能看到账户余额
- 任务提交后超过 6 小时还没有结果，会停止自动查询并标为「查询超时」，之后可以手动「再查一次」
- 上传前检查文件大小（图片 30 MB、视频 50 MB、音频 15 MB），超过会直接说明

## 数据存在哪里

都在 `data/` 目录，只在本机：

| 文件 | 内容 |
| - | - |
| `data/config.json` | API Key |
| `data/history.json` | 创作记录 |
| `data/assets.json` | 素材库列表和缩略图 |
| `data/canvases.json` | 画布项目：名称、封面、节点、连线和视口 |
| `data/characters.json` | 角色：名字、描述和参考图的地址。参考图的文件在 `data/uploads/` 里 |
| `data/skills.json` | 自己建的技能：名称、说明、用在视频还是图片、规则。官方技能在代码里（`shared/skills.ts`） |
| `data/videos/` | 生成完成后自动保存的视频 |
| `data/images/` | 生成的图片 |
| `data/audio/` | 生成的语音、音效、配乐 |
| `data/uploads/` | 从电脑里选来当输入的文件（Grok 的首帧、要配乐的视频）。删除记录不会删掉它们，用不着了可以手动清理 |

也可以不把 Key 存进文件，改用环境变量：`FLATKEY_API_KEY=sk-fk-... npm start`（火山方舟的是 `ARK_API_KEY`）。

## 两个平台

在「设置」的「模型平台」里选用哪个平台生成。两个平台的 Key 各存各的，换过去再换回来不用重填。换平台只影响之后新提交的生成；已经提交的任务仍然回它原来的平台查询。

| | 火山方舟 | Flatkey |
| --- | --- | --- |
| 视频模型 | Seedance 2.5、2.0、2.0 Fast、2.0 Mini | Seedance、Grok |
| 文生视频、首尾帧、参考图 | 有，图片直接用本机的文件 | 有，Seedance 的素材要先传进素材库 |
| 参考视频、参考音频 | 页面上加不了：接口只收公网的 https 链接，本机的文件发不过去，而这里不提供填链接 | 有，从素材库选 |
| 延长和编辑视频 | 没有 | 有 |
| Seedance 的联网搜索、超分、时长自动、比例自适应 | 没有（水印固定关着） | 有 |
| 提示词润色 | 豆包的文本模型 | Claude、GLM、Grok |
| 图片 | Seedream 5.0 pro、5.0 flash、5.0，可以带参考图 | Grok |
| 语音 | 豆包语音合成 2.0，230 个音色，不能试听。要另填一个豆包语音的 Key | ElevenLabs，音色能试听、能按语言筛 |
| 音效、配乐、素材库、真人档案 | 还没有接 | 有 |
| 账户余额 | 读不到，要到火山引擎控制台的费用中心看 | 设置里能看 |

选了火山方舟之后，它没有的那些创作类型和页面不显示。它的型号和各自支持的分辨率、比例、时长登记在 `shared/models.ts`（方舟没有能用 API Key 读的模型列表），官方出了新版本要到那里改。

用火山方舟之前要先在火山引擎做三件事：给账户充值（余额大于 200 元才能开通 Seedance 2.0、2.5），在火山方舟控制台的「开通管理」里开通要用的模型，再创建一个 API Key。个人账号同时最多跑 3 个视频任务（4K 是 1 个），多的会排队。语音用的是火山引擎的另一个产品「豆包语音」：要另外开通「语音合成大模型」，在豆包语音控制台创建 Key，填在设置最下面那一栏；它和火山方舟的 Key 不通用，也可以用环境变量 `DOUBAO_SPEECH_API_KEY`。Seedance 不收带真人人脸的参考图和参考视频。

火山方舟这一列在 2026-10-09 用真实接口跑过：Seedance 2.0 Mini 的文生视频、首帧、首尾帧、参考图、图加视频加音频的参考生成，Seedream 5.0 flash 生图，豆包润色。接口返回的用量和官方标价对得上（480p 5 秒约 1.16 元）。其余型号走的是同一段代码，没有逐个跑；4K 没有跑过。

### 连接 Flatkey 时断时续

Node 默认不走系统代理。如果你的电脑要靠代理才能稳定访问外网，页面上会时不时出现「连接 Flatkey 失败」。这时让服务读取终端里的代理设置（`HTTPS_PROXY`）：

```bash
NODE_USE_ENV_PROXY=1 npm start
```

这个开关在 Node 22.23 上验证过。

## 测试

```bash
npm test
```

先做类型检查，再用模拟的 Flatkey 和火山方舟接口跑一遍主要流程（视频、图片、语音、音效、配乐、润色、素材、真人档案、切换平台），不花钱，也不会用到真实的 Key 和 `data/`。

调界面时可以用 `npm run dev:mock` 另起一份接模拟接口的应用（<http://127.0.0.1:5179>）。

写界面代码时用 `npm run dev`：页面在 <http://127.0.0.1:5173>，改了代码立刻生效，接口转给 5178 上的本地服务（要先把它启动起来；想接模拟接口就用 `PORT=5179 npm run dev`）。

改完界面要做整体走查（深色、浅色各一遍），命令和检查项见 `DESIGN.md` 第 11 节。

## 结构

- `server.js`：本地服务。托管页面、保管 Key、把请求转发给当前选的平台、轮询任务、保存生成结果。只监听 `127.0.0.1`，并拒绝其他网站发来的跨站请求。
- `shared/models.ts`：模型登记表。两个平台各自能用什么、每个模型属于哪一族、型号后面的附注、能选的分辨率和时长、润色时用的提示词规则都在这里，页面和服务都读它。加新模型先改这个文件。
- `web/`：页面。React 加 TypeScript，用 Vite 构建到 `web/dist/`，由 `server.js` 托管。
  - `web/src/ui/`：基础控件、浮层和弹窗、图标。
  - `web/src/composer/`：创作输入框。`state.ts` 是状态和动作，`Composer.tsx` 是界面。
  - `web/src/store.ts`：全局状态、接口调用、轮询。
  - 其余一页一个文件：`history.tsx`（创作记录）、`assets.tsx`（素材库）、`persons.tsx`（真人档案）、`settings.tsx`（设置）。
- `test/`：模拟接口和自动化测试。
- `DESIGN.md`：界面的视觉规范（对标 Antigravity 与 Codex 的深色工作台），改界面前先看它。

接口文档：Flatkey 的在 <https://docs.flatkey.ai/zh/guides/seedance>，火山方舟的在 <https://www.volcengine.com/docs/ark/create-video-generation-task-api>（视频）和 <https://docs.volcengine.com/docs/ark/image-generation-api>（图片）。语音、音效、配乐这几个接口 Flatkey 的文档里没有写，这里用的格式是对着真实接口试出来的，写在 `server.js` 对应的路由里。
